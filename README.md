## 🎯 About the Course

Machine Learning Zoomcamp follows the complete path from a machine learning problem to a production service:

> Frame the problem → prepare the data → train and evaluate the model → expose it through an API → package it → deploy it.

**Tech stack covered:** Python, NumPy, pandas, scikit-learn, TensorFlow, PyTorch, FastAPI, Docker, Kubernetes, and AWS Lambda.

---

## 🧠 Skills I Will Obtain From This Course

By the end of the course, I will be able to:

**Machine Learning Foundations**
- Frame ML problems using the CRISP-DM framework
- Compare ML systems with rule-based systems and know when to use which
- Understand the foundations of supervised learning

**Regression & Classification**
- Build regression models (linear regression from scratch and with scikit-learn)
- Build classification models (logistic regression) for real-world tasks like churn prediction
- Engineer, select, and interpret features
- Apply regularization to improve models
- Encode categorical variables and interpret feature importance

**Model Evaluation**
- Use accuracy, precision, recall, and F1 score
- Build and interpret confusion matrices
- Use ROC curves and AUC
- Validate models with cross-validation
- Evaluate models on imbalanced datasets

**Deployment & MLOps**
- Serialize trained models
- Expose predictions through a FastAPI web service
- Package services with Docker
- Deploy models to the cloud
- Deploy serverless models with AWS Lambda and API Gateway
- Understand the serverless deployment model

**Tree-Based & Deep Learning**
- Train and interpret decision trees
- Build random forests and use gradient boosting with XGBoost
- Tune hyperparameters systematically
- Understand neural network components
- Work with PyTorch, TensorFlow, and Keras
- Train convolutional neural networks and apply transfer learning

**Production ML Systems**
- Understand core Kubernetes concepts for model deployment
- Serve models with TensorFlow Serving
- Deploy and scale model-serving components on Kubernetes
- Distribute traffic and scale services

**Project & Professional Skills**
- Build end-to-end ML projects from problem framing to deployment
- Create portfolio-ready projects for GitHub
- Learn in public and document progress
- Participate in peer review and community support
